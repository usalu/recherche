# 1.1.3 Bauteil-Daten

## Struktur

- 1.1.3 Bauteil-Daten
  - 1.1.3.1 Mindestdaten zum Entwerfen
  - 1.1.3.2 Abgeleitete / angereicherte Daten

## 1.1.3 Bauteil-Daten

Der Seed erzeugt zwei Arten von Daten:

```text
A. Mindestdaten zum Entwerfen
Daten, die sofort gebraucht werden, damit der Generator ein Vorplanungsobjekt erzeugen kann.

B. Abgeleitete / angereicherte Daten
Daten, die das Tool aus Mindestdaten berechnet, schätzt oder später ergänzt.
```

Beispiel:

```text
Manuell eingegeben:
Wandplatte, 18 Stück, 3.20 × 1.20 × 0.18 m, Stahlbeton, Quelle Basel, verfügbar Q2 2027

Automatisch abgeleitet:
Volumen, Masse, Fläche, Transportdistanz, grobe CO₂-Wirkung, mögliche Ports, fehlende Nachweise, ReUse-Reifegrad
```

---

## 1.1.3.1 Mindestdaten zum Entwerfen

Die Mindestdaten ermöglichen erste Entwurfsfragen:

```text
Kann das Bauteil ein Raster bilden?
Reicht die Menge für ein System?
Kann daraus ein Katalogobjekt erzeugt werden?
Welche Rolle kann das Bauteil übernehmen?
Welche Nachweise fehlen noch?
```

Die Informationen dienen ausschließlich der Vorplanung und ersetzen keine statischen Nachweise.

---

## 1.1.3.2 Abgeleitete / angereicherte Daten

Automatisch erzeugte Informationen können umfassen:

```text
- Bounding Box
- Fläche
- Volumen
- Masse
- CO₂-Potenzial
- Transportdistanz
- Serienlogik
- Generatorgrammatik
- Ports
- fehlende Strukturinformationen
- fehlende Energiedaten
- fehlende Nachweise
- Datenvertrauen
- ReUse-Reifegrad
```

Dadurch wird der manuelle Eingabeaufwand reduziert und die Datenbasis erweitert.
