# 1.1.1 Eingabeprozess

## Struktur

- 1.1.1 Eingabeprozess
  - 1.1.1.1 User Input
  - 1.1.1.2 API / Import aus Bauteilbörse

## 1.1.1 Eingabeprozess

Der Einstieg erfolgt über eine einfache Kombination aus Bildmaterial, kurzer Beschreibung und wenigen Pflichtangaben.

Beispiel:

> „Das ist eine Stahlbeton-Wandplatte aus einem Rückbau. Es gibt ungefähr 18 Stück. Die Platten sind ca. 3,20 m hoch, 1,20 m breit und 18 cm dick. Sie stammen aus einem Fertigteilbau und könnten als tragende oder raumbildende Elemente im neuen Entwurf geprüft werden.“

Dazu kommt ein Foto, Scan oder Bauteilbörsenbild.
Das System extrahiert daraus eine erste Lesart: Typologie, Menge, Maße, Materialfamilie, Zustand, Quelle und mögliche Zielrolle.

---

## 1.1.1.1 User Input

Der Input basiert auf drei Informationsquellen:

```text
1. Bild
Foto, Scan, Screenshot oder Bauteilbörsenbild

2. Prompt
Kurze Beschreibung in natürlicher Sprache

3. Pflichtfelder
Nur Informationen, die nicht automatisch erkannt werden können
```

Bei Stahlbetonbauteilen liefern Bilder nicht nur visuelle Informationen, sondern auch Hinweise auf Geometrie, Anschlüsse, Öffnungen, Schäden und Schnittflächen.

---

## 1.1.1.2 API / Import aus Bauteilbörse

Bauteile aus Inventaren oder Bauteilbörsen können direkt übernommen werden.

Importierte Informationen können umfassen:

```text
- Listing-ID
- Quelle
- Standort
- Menge
- Status
- Verfügbarkeit
```

Der Import reduziert den manuellen Aufwand und stellt gleichzeitig die Verbindung zum realen Bauteil sicher.
