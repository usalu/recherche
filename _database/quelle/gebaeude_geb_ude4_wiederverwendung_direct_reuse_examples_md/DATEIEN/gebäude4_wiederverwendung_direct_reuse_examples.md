# Corrected Wiederverwendung / Direct Reuse Priority List

**Version:** corrected after rule update  
**Core change:** the top priority is now reserved for **load-bearing Wiederverwendung**. Interior reuse is allowed only when it consists of **fixed spatial architectural elements**, not loose furniture or decoration.

---

## 1. Corrected definition

**Wiederverwendung / direct reuse** means that an existing building or construction element is used again **as a building, spatial, technical, envelope, or structural element**, with little or no material reprocessing.

It counts when the reused element is used again as:

- **load-bearing structure:** beams, columns, slabs, trusses, structural frames, load-bearing walls, stair structures
- **envelope / weathering layer:** façade panels, windows, cladding, roof tiles, roof sheets, external doors, insulation, shading structures
- **spatial architectural interiors:** fixed partitions, interior glazing, doors, balustrades, stairs, raised floors, acoustic ceilings, fixed sanitary cores, built-in spatial joinery
- **technical building elements:** radiators, ducts, sanitary equipment, lighting systems, cable trays, HVAC units, if they are fixed parts of the building

It does **not** count when it is only:

- loose furniture
- decoration
- movable lamps, loose desks, chairs, shelving, or accessories
- surface finishes only, unless they form a fixed construction/spatial element
- design-for-disassembly only, without actual reused components
- ordinary **Sanierung / Bestandserhalt** where the existing structure remains in place and continues doing exactly the same job, with no transformed or additional reused building components

---

## 2. Corrected rating logic

| Rating | Corrected meaning |
|---|---|
| **★★★★★** | Built project where **load-bearing reused construction elements** are central to the architectural and structural concept. This is the highest-priority Wiederverwendung category. |
| **★★★★☆** | Built project with important but partial load-bearing reuse, or exceptionally strong envelope/spatial reuse. Also includes major transformation projects where reused structural elements are significant but not dominant. |
| **★★★☆☆** | Built project with real reused construction elements, but mainly envelope, fixed spatial interiors, access elements, technical systems, or Sanierung-adjacent transformation. |
| **★★☆☆☆** | Prototype, pavilion, demonstrator, proposal, competition, small project, or unbuilt/in-development case with direct construction-element reuse. |
| **★☆☆☆☆** | Very minor fixed/spatial reuse. Use rarely. |
| **Remove / appendix only** | Loose furniture, decoration, finishes-only, DfD-only, or unverifiable circularity claims without direct reused construction elements. |

**Compact rule:**  
Higher score = reused building elements do more **structural, spatial, or envelope work**.  
Highest score = reused elements are **load-bearing** and central.

## 8. Main correction summary

1. **★★★★★ is now only for load-bearing Wiederverwendung.**  
   Projects with only envelope reuse, no matter how strong, should not be five-star.

2. **Sanierung / Bestandserhalt is not enough.**  
   If an existing structure remains in place and keeps doing the same job, it is not counted as high-priority Wiederverwendung. It can support the project narrative, but it should not drive the rating.

3. **Interior reuse can stay if it is spatial.**  
   Fixed partitions, interior glazing, stairs, balustrades, sanitary cores, ceiling systems, and technical elements can count. Loose furniture cannot.

4. **Furniture and decoration do not count.**  
   They should be removed or ignored when rating a project.

5. **Envelope reuse remains valid but lower than load-bearing reuse.**  
   Reused windows, cladding, bricks, roof elements, and façade panels usually belong in ★★★☆☆–★★★★☆ unless they are also load-bearing.

6. **Proposals and competitions are capped low.**  
   They can stay as research references but should not outrank built projects.
