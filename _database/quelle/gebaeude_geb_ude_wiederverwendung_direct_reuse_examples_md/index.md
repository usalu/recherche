# gebaeude_geb_ude_wiederverwendung_direct_reuse_examples_md

Structured working list prioritising **complex built reuse**, especially cases with **structural** and **envelope** relevance. Proposals, competitions, pilots and demonstrators are included but ranked lower unless direct built component reuse is clearly documented.

## Inclusion logic

- **Included:** 1:1 direct reuse / Bauteil-Wiederverwendung examples; built projects, in-progress projects, pilots, demonstrators, proposals and competitions.

- **Prioritised:** reused load-bearing elements, reused façade/envelope elements, full design → sourcing → testing → fabrication → construction chains.

- **Deprioritised:** DfD-only concepts, general renovation/Sanierung without clear component reuse, purely recycled-content examples, interiors/fit-outs unless the reuse is especially clear.

## Rating logic

- **★★★★★** = complex built reuse, structural/envelope relevance, design→build chain.

- **★★★★☆** = strong built reuse, but smaller / less structural / partly transformation.

- **★★★☆☆** = built reuse, but mostly non-structural, fit-out, façade, pilot, or uncertain completion status.

- **★★☆☆☆** = pavilion / prototype / proposal / small-scale reuse / DfD-heavy project.

- **★☆☆☆☆** = very small built reuse relevance.

- **Montessori Maassluis**: keep at ★★★★ only if completion and actual installation of reused hollow-core slabs are confirmed.
- **Juch-Areal Recyclingzentrum**: strong candidate but should stay lower/provisional until built completion is confirmed.
- **Fabrix / Roots in the Sky**, **Circular Centre Netherlands**, and **CIRCuIT retail-unit frame reuse**: high structural relevance, but proposal/in-progress/demonstrator status keeps the rating lower.
- **Brummen Town Hall** and **Moringa Hamburg**: important circular/DFD precedents, but not high-priority Wiederverwendung unless direct installed second-life components are documented.
- Rows marked **to map / verify** need actor-list alignment and source checking before final publication.

## Suggested sorting categories

1. **Built structural reuse** — top priority.
2. **Built envelope/façade reuse** — second priority.
3. **Built transformation with direct component reuse** — useful, but mark Bestand/self-reuse clearly.
4. **Built fit-out/interior reuse** — include only where the case is strategically relevant.
5. **Pavilions, prototypes, proposals and competitions** — include, but assign lower stars unless they became built at meaningful scale.
