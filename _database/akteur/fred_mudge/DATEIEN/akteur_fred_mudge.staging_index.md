# Fred Mudge — relevance to reuse

## Reuse relevance at a glance

Fred Mudge is directly relevant to reuse through **ReCreate Studio**, a design software project for creating new building structures from a database of reused concrete components.

TU/e lists his 2024 EngD thesis as **“ReCreate Studio: Design software for new building structures from a database of reused concrete components.”** ReCreate also describes his BIM software work as a way to let designers browse a library of previously used building components, import desired elements into a 3D BIM environment, and place them into a new design assembly.

## Why his work matters for reuse

A major barrier to reuse is not only whether components exist, but whether architects and engineers can actually design with them. Reused components have fixed dimensions, known or uncertain properties, and specific condition data. This creates a design problem that ordinary BIM workflows do not fully solve.

Mudge’s relevance is strongest in the digital workflow that makes reuse practical:

1. **Making recovered components visible to designers**  
   A database/library of reusable elements allows designers to see what is available instead of designing from abstract new-product catalogues.

2. **Bringing reuse into BIM**  
   Importing recovered components into a BIM environment helps integrate reuse into normal architectural and structural workflows.

3. **Supporting design decisions with data**  
   For reuse to be safe and efficient, designers need information about geometry, component type, structural capacity, carbon impact, and assembly constraints.

4. **Turning reuse into a repeatable process**  
   Software can reduce the effort needed to test whether a set of recovered components can become a viable new structure.

## Link to ReCreate

Mudge’s work is directly part of the ReCreate ecosystem. ReCreate’s broader aim is to close the loop for concrete by deconstructing and reusing precast structural components. Mudge’s software work supports the design side of that loop: helping designers use the recovered components once they are documented.

## Best way to describe him in a reuse-focused project
