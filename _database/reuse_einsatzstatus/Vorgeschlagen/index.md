# Vorgeschlagen

## Kurzdefinition

**Vorgeschlagen** bezeichnet einen Reuse-Einsatz, der als Idee, Konzept, Wettbewerbsbeitrag oder planerischer Vorschlag beschrieben ist, ohne dass eine Umsetzung oder ein Abbruch belegt ist.

## Abgrenzung

- Sobald eine Umsetzung konkret terminiert oder in Ausführung ist, ist `Geplant` präziser.
- Sobald der Vorschlag aufgegeben oder ersetzt wurde, ist `Verworfen` präziser.
