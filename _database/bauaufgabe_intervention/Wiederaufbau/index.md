# Wiederaufbau

## Kurzdefinition

Wiederaufbau bezeichnet den erneuten Aufbau eines zuvor demontierten Bauobjekts oder groesserer Bauteilgruppen, oft mit Anpassungen an einen neuen Ort oder eine neue Nutzung.
