## Graph modelling notes

- Store **carbon reductions** separately from **CO₂-Kosten** unless a source actually monetises the carbon.
- Several projects report large CO₂ savings, but most do **not** convert those into avoided carbon-price costs.
- For those, model `CO2_Einsparung` as an environmental outcome and add a derived `CO2-Kosten` node only if your own scenario model applies a carbon price.
- Use project-level relationships only when the source explicitly discusses the economic effect for the named project or programme.
