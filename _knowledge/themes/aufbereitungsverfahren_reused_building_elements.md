## Scope

This note identifies typical and documented `Aufbereitungsverfahren` for reused building elements across eight material groups:

1. Stahl  
2. Holz  
3. Beton / Stahlbeton / Hohlkörperdecken  
4. Glas / Drahtglas  
5. Ziegel / Naturstein / Mauerwerk  
6. Dämmstoff / Mineralwolle  
7. Aluminium  
8. Lehm / Stroh / bio-based materials  

The table separates **documented project evidence** from **general reuse relevance**. Where only a corpus signal or general best practice was found, the row explicitly says so.

## Evidence legend

- **Documented project evidence**: A named project/source documents the material reuse and/or the process.
- **Corpus signal**: The internal corpus indicates a likely process/project relationship, but the source should be verified before creating a project edge.
- **General best practice**: A process is generally relevant for reuse but was not documented in a specific corpus project during this pass.
- **Not found**: No project documentation found; do not create project evidence edges.
