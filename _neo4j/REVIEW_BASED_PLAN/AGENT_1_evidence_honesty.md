## §1 Cold-start context

The `mit-bestand` Neo4j graph at `bolt://localhost:7687` is a knowledge graph about building-element reuse. It has 3,802 nodes, 25,023 relationships, 51 non-empty labels, 64 non-empty rel types as of 2026-05-21. Every relationship carries an evidence triplet (`evidence_origin`, `evidence_basis`, `evidence_confidence`) plus `evidence_source_id` and (sometimes) `evidence_excerpt`.

A three-layer skeptical review (see [REVIEW_BASED_PLAN.md](../REVIEW_BASED_PLAN.md)) found that the recent radical-quality-reset migrations used the audit gates as a driver for data rewrites instead of as failure detectors. Specifically:

- `Repair D` promoted 254 `HAT_BAUTEILGRUPPE` edges from `evidence_origin='derived'` to `'curated'` with auto-generated `evidence_excerpt` text strings that just restate graph topology.
- `Repair D` filled 1,500+ already-`curated`-but-missing-excerpt edges with template strings (`'Akteursregister (q_akteursliste_master_md): Akteur ... [id] tritt in Rolle ...'`).
- 22 list-typed `evidence_origin` properties (from `apoc.refactor.mergeNodes(properties:'combine')` in Phase 1.6) were unpacked with "alphabetical priority" picking `curated` over `derived`.
- 243 `BELEGT_IN` edges had `evidence_basis='research_file_row'` silently rewritten to `'cell_citation'` to satisfy an enum audit.
- 703 `ANCHORED_BY` edges (bookkeeping plumbing for the 2 OntologyAnchor nodes) carry `evidence_confidence='bookkeeping'` — a process-state value polluting an epistemic enum.

Your job is to make the evidence model honest enough that downstream users can trust filters like `WHERE r.evidence_origin='curated'`.

## §2 Mission

### §2.1 Phase R1 — `evidence_origin` split + `is_bookkeeping` flag

**Goal:** Replace the current 3-value `evidence_origin ∈ {curated, inferred, derived}` enum with a 5-value enum that distinguishes source-curated cells from topology-synthesized auto-fills. Move `bookkeeping` out of `evidence_confidence` to its own boolean flag.

**New enums:**

```
evidence_origin ∈ {
  source_curated,        // verbatim cell from a source document
  topology_synthesized,  // generated by a migration from graph topology (Repair D et al.)
  registry_derived,      // from a master registry (q_akteursliste_master_md)
  inferred,              // from a rule (era×material, year→era)
  external_unfolded      // from a citation array via mig_4c_1
}
evidence_confidence ∈ {belegt, teilweise_belegt, unklar, inferiert}   // bookkeeping removed
```

**New edge property:** `is_bookkeeping: bool` (default false; set true for the 703 `ANCHORED_BY` edges).

### §2.2 Phase R8 — `:DataIssue` audit relationship

**Goal:** Make audit findings queryable graph artefacts rather than triggers for data rewrites. Seed `:DataIssue` nodes for every Repair-D-promoted edge, every inferred pollutant, every unverified actor stub, every orphan dossier (post R7).

**New label:**

```
:DataIssue {
  id,
  kind,              // enum, see §6.2 below
  severity,          // 'low' | 'medium' | 'high' | 'critical'
  ref_label,         // the label of the concerned node
  ref_id,            // the id of the concerned node (or 'edge:<rel_id>')
  rel_type,          // optional, when issue is about an edge
  found_at,
  found_by,          // 'r8_audit_seed' for this initial pass
  status,            // 'open' | 'in_review' | 'resolved' | 'wont_fix' | 'false_positive'
  resolution_note    // free text
}

(:DataIssue)-[:CONCERNS]->(<any node>)
```

## §7 Runner script template

Save as `_neo4j/intake/runs/2026-05-21_review_based_plan/agent_1_evidence_honesty/logs/agent_1_runner.py`. Skeleton:

```python
"""Agent 1 runner — R1 (evidence_origin split) and R8 (DataIssue seed).

R1 is run in Stage 1. R8 is run in Stage 4 (orchestrator gates it).
"""
import json
import sys
from datetime import datetime, timezone
from pathlib import Path

from neo4j import GraphDatabase
sys.path.insert(0, str(Path(__file__).resolve().parents[5] / '_scripts'))
from neo4j_env import resolve_connection  # noqa

RUN_DIR = Path(__file__).resolve().parents[1]
MIG_DIR = RUN_DIR / 'migrations'
LOG_DIR = RUN_DIR / 'logs'
REPORT_DIR = RUN_DIR / 'reports'
FLAGS_DIR = RUN_DIR


def run_phase(phase: str, migration_filename: str, expected_audits: dict):
    conn = resolve_connection()
    driver = GraphDatabase.driver(conn['uri'], auth=(conn['user'], conn['password']))

    # Pre-probe
    pre = {}
    with driver.session(database='mit-bestand', default_access_mode='READ') as s:
        pre['total_rels'] = s.run('MATCH ()-[r]->() RETURN count(r) AS c').single()['c']
        pre['origin_distribution'] = {
            row['origin']: row['c']
            for row in s.run(
                'MATCH ()-[r]->() WHERE r.evidence_origin IS NOT NULL '
                'RETURN r.evidence_origin AS origin, count(r) AS c'
            )
        }
        pre['confidence_distribution'] = {
            row['conf']: row['c']
            for row in s.run(
                'MATCH ()-[r]->() WHERE r.evidence_confidence IS NOT NULL '
                'RETURN r.evidence_confidence AS conf, count(r) AS c'
            )
        }
    (LOG_DIR / f'{phase}_probe_pre.json').write_text(json.dumps(pre, indent=2))

    # Execute migration statement by statement (split on `;` at start of line)
    migration_text = (MIG_DIR / migration_filename).read_text()
    statements = [s.strip() for s in migration_text.split(';') if s.strip() and not s.strip().startswith('//')]
    audit_jsonl = LOG_DIR / f'{phase}_audit.jsonl'
    with driver.session(database='mit-bestand', default_access_mode='WRITE') as s, \
         audit_jsonl.open('w', encoding='utf-8') as audit_fp:
        for i, stmt in enumerate(statements):
            t0 = datetime.now(timezone.utc)
            try:
                result = s.run(stmt + ';')
                records = [r.data() for r in result]
                summary = result.consume()
                audit_fp.write(json.dumps({
                    'statement_index': i,
                    'started': t0.isoformat(),
                    'elapsed_ms': (datetime.now(timezone.utc) - t0).total_seconds() * 1000,
                    'records': records[:5],  # cap at 5 for brevity
                    'counters': summary.counters.__dict__,
                }) + '\n')
            except Exception as exc:
                audit_fp.write(json.dumps({
                    'statement_index': i,
                    'error': str(exc),
                    'statement_preview': stmt[:200]
                }) + '\n')
                raise

    # Post-probe
    post = {}
    with driver.session(database='mit-bestand', default_access_mode='READ') as s:
        post['total_rels'] = s.run('MATCH ()-[r]->() RETURN count(r) AS c').single()['c']
        post['origin_distribution'] = {
            row['origin']: row['c']
            for row in s.run(
                'MATCH ()-[r]->() WHERE r.evidence_origin IS NOT NULL '
                'RETURN r.evidence_origin AS origin, count(r) AS c'
            )
        }
    (LOG_DIR / f'{phase}_probe_post.json').write_text(json.dumps(post, indent=2))

    # Acceptance gates
    verified = True
    gate_results = {}
    with driver.session(database='mit-bestand', default_access_mode='READ') as s:
        for gate_name, gate_check in expected_audits.items():
            value = s.run(gate_check['cypher']).single()
            gate_results[gate_name] = dict(value) if value else None
            if gate_check.get('expect_zero') and value and value.get('violations', 0) > 0:
                verified = False
            if gate_check.get('expect_exactly') is not None and value.get('c') != gate_check['expect_exactly']:
                verified = False

    # Done flag
    (FLAGS_DIR / f'PHASE_{phase.upper()}_DONE.flag').write_text(json.dumps({
        'phase': phase,
        'agent': 'agent_1_evidence_honesty',
        'completed_at_utc': datetime.now(timezone.utc).isoformat(),
        'verified': verified,
        'verification_query_results': gate_results,
        'extra': {
            'pre_total_rels': pre['total_rels'],
            'post_total_rels': post['total_rels']
        }
    }, indent=2))

    driver.close()
    if not verified:
        raise SystemExit(f'Phase {phase} verification FAILED. See logs/{phase}_audit.jsonl')


if __name__ == '__main__':
    phase = sys.argv[1] if len(sys.argv) > 1 else 'r1'
    if phase == 'r1':
        run_phase('r1', 'mig_r1_evidence_origin_split.cypher', {
            'old_curated_remaining': {'cypher': "MATCH ()-[r]->() WHERE r.evidence_origin='curated' RETURN count(r) AS violations", 'expect_zero': True},
            'bookkeeping_in_confidence': {'cypher': "MATCH ()-[r]->() WHERE r.evidence_confidence='bookkeeping' RETURN count(r) AS violations", 'expect_zero': True},
            'is_bookkeeping_count': {'cypher': "MATCH ()-[r {is_bookkeeping:true}]->() RETURN count(r) AS c", 'expect_exactly': 703},
        })
    elif phase == 'r8':
        run_phase('r8', 'mig_r8_data_issue_seed.cypher', {
```
