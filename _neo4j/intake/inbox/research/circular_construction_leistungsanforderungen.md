# Leistungsanforderungen für wiederverwendete Bauteile in einem Circular-Construction-Knowledge-Graph

**Kontext:** Knowledge-Graph-Label `Leistungsanforderung`  
**Bestehende Nodes:**  
`la_dauerhaftigkeit`, `la_tragfaehigkeit`, `la_brandschutz`, `la_feuchteschutz`, `la_waermeschutz`, `la_schallschutz`, `la_rueckbaubarkeit`, `la_schadstofffreiheit`, `la_feuerwiderstand`, `la_f90`, `la_r90`, `la_rei90`

**Legende:**  
- **M** = rechtlich verpflichtend, wenn das Bauteil diese regulierte Funktion erfüllt  
- **P** = üblicherweise durch Normen oder Ingenieurpraxis erforderlich  
- **R** = wiederverwendungsspezifischer Nachweisbedarf  

**Wichtiger Modellierungsgrundsatz:**  
Allgemeine Code-/Normanforderungen sollten von projekt- oder bauteilgruppenspezifisch dokumentierten Anforderungen getrennt werden.  
Eine Graph-Kante sollte nur empfohlen werden, wenn die Anforderung für ein Projekt oder eine Bauteilgruppe dokumentiert ist.

## 3. Fire resistance: documenting F90, R90, REI90

**F90** is best treated as a German/DIN-style fire-resistance class, while **R90** and **REI90** are EN-style performance classes:

- **R** = load-bearing capacity
- **E** = integrity / room closure
- **I** = insulation under fire

EN 13501-2 classifies construction products and building elements using fire-resistance test data, smoke-control data, relevant mechanical tests, and direct or extended application of test results. Source: https://standards.iteh.ai/catalog/standards/cen/6f992261-dd87-44fd-90a0-d52dc526bf0b/en-13501-2-2023

| Proof type | Typical evidence object to store |
|---|---|
| Fire test + classification | EN 13501-2 classification report, DIN 4102 test/classification report, VKF recognition, UK assessment/classification report |
| Calculation | Eurocode fire design calculation, e.g. EN 1992-1-2 / EN 1993-1-2 / EN 1995-1-2; in the Netherlands, NEN fire calculation routes are also used with NEN 6069/NEN 607x context. |
| Product/system declaration | DoP/CE/ETA for the exact product or system, including field of application. |
| Reuse-specific verification | Inspection report confirming condition, dimensions, remaining protection, corrosion/char/damage, connections, coatings, and that the old rating still applies or has been re-established in the new assembly. |

## 4. Recommended graph modeling

Model `F90`, `R90`, and `REI90` as controlled child/class nodes under fire resistance, not as peer requirements beside `Brandschutz`.

```text
la_brandschutz
  └── la_feuerwiderstand
        ├── la_f90
        ├── la_r90
        └── la_rei90
```

Recommended interpretation:

- Use `la_brandschutz` for the general fire-safety requirement.
- Use `la_feuerwiderstand` for the performance dimension.
- Use `la_f90`, `la_r90`, or `la_rei90` only when the exact class is documented.
- Do not tag a steel beam with `la_rei90` when only `la_r90` load-bearing fire resistance was proven.
- Do not infer `F90/R90/REI90` from material type alone.

## 5. Recommended graph actions summary

| Action | Recommendation |
|---|---|
| Add more `la_rueckbaubarkeit` | Yes, but only for components or projects with documented demountability, design-for-disassembly, reversible connections, or actual reuse route. |
| Add more `la_schadstofffreiheit` | Yes. This is likely under-tagged for reused timber, insulation, interior fit-out, façade/glazing sealants, coatings, and masonry from contaminated sources. |
| Use fire-class nodes | Yes, but only where class is explicitly documented. |
| Treat F90/R90/REI90 as child nodes | Yes. Recommended hierarchy: `la_brandschutz` → `la_feuerwiderstand` → specific class node. |
| Create country-specific legal edges | Only when the project location or Bauteilgruppe country scope is known. |
| Create project-specific requirement edges | Only when supported by a project document, calculation, test report, DoP/ETA, classification report, approval, material passport, or specification. |
| Avoid over-tagging | Do not attach `Tragfähigkeit` to non-loadbearing windows/panels; do not attach `Schallschutz` unless separating/acoustic function is documented; do not attach `REI90` where only R90 is proven. |
