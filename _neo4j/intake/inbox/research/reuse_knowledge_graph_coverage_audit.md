# Circular construction reuse KG — final research coverage audit

**Audit date:** 2026-05-16  
**Scope:** final evidence sweep for Materialpass / Madaster / Concular / digital-twin evidence, stub project promote-or-drop decisions, and actor nodes with ambiguous or missing project evidence.  
**Decision rule:** promote a `Projekt` node only where there is project-specific primary evidence or a reliable case study. If evidence is programme-, publication-, network-, tool-, or actor-level, do **not** promote as a project; model the item as `Akteur`, `Tool`, `Programm`, `Forschung`, or `Publikation`.

## Evidence-confidence legend

- **A — primary / strong case study:** project owner, architect, platform, university, public agency, or peer-reviewed/reputable case page names the item and the circular/reuse strategy.
- **B — reliable secondary:** credible architecture/industry case study; details sufficient for modelling but not always full donor/test data.
- **C — weak / registry-only:** only appears in a directory/listing, or source gives insufficient project-specific detail.
- **D — not found in this sweep:** no reliable project evidence found; avoid full project node until further source is supplied.
