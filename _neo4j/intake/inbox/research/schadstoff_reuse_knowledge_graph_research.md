## Highest-priority verification targets

1. **Europa Building Brussels** — reclaimed timber windows; verify lead paint, wood preservatives, PCB sealants/glazing putty, asbestos in associated old components.
2. **Plattenpalast Berlin / Berlin Schildow Pilot House / Superlocal Expogebouw Bleijerheide** — reused precast concrete and high-rise components; verify PCB joints/sealants, asbestos, PAH/bitumen, KMF if insulation was disturbed or reused.
3. **CRCLR House / Impact Hub Berlin** — reused MDF and old industrial-building context; verify formaldehyde, lead/heavy metals, wood preservatives, asbestos/PCB in existing fabric.
4. **BioPartner 5 Leiden** — donor steel/lab-building provenance; verify coatings/heavy metals, PCB, asbestos, and potential lab-building contamination where applicable.
5. **Big Dig Building Boston** — infrastructure elements; verify PAH, heavy metals, coatings, PCB sealants, asbestos gaskets/old infrastructure materials.
6. **Hastings Pier Visitor Centre** — pier timber and fire/older marine context; verify wood preservatives, PAH/creosote, lead/heavy metals in coatings.

## Conservative graph-action pattern

Use project-level `Schadstoff` edges only for **BELEGT** evidence. For current evidence, prefer these non-assertive patterns:

```text
Material/Bauteilgruppe --hasRiskPollutant--> Schadstoff
Project --requiresVerificationFor--> Schadstoff
Project --usesMaterial--> Material
Schadstoff --riskCondition--> Baujahr / Material / Bauteiltyp / Nutzungskontext
```

Avoid:

```text
Project --hasSchadstoff--> Schadstoff
```

unless a project audit, material passport, lab test, specification, or project source explicitly documents the pollutant.
