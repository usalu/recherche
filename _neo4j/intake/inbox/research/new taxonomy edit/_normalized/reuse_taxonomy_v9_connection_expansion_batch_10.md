Before this batch, the coverage audit found 79/81 projects with row-level Markdown evidence and two projects with only Batch 01 summary coverage. This batch adds explicit row-level evidence rows for both missing projects. The research set therefore has row-level Markdown evidence for all 81 topology projects, subject to later deduplication and review.

- K118 steel, stair, windows, granite, metal sheets, roof elements, doors, parquet, fixtures and PV are evidence-backed component candidates. The future import-prep pass still needs to merge candidates with any hidden or renamed existing `Bauteilgruppe` IDs in the graph.
- MedUni fluorescent tubes, copper cables and aluminium cable ducts/raster grids are held as review/material-recovery rows. They are not direct component-reuse rows unless a stronger reuse-specific source is found.
- MedUni doors-as-cladding remains unresolved from Batch 01. This batch adds a safer generic doors component row but does not assert the cladding transformation.
- All rows remain `import_ready = FALSE` because this is still the evidence-expansion phase.
